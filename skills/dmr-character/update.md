# Update a Character

A change to the Character as it is, edited in place with no past Build: equipment, attunement, prepared spells, coins, the identity (backstory, appearance, personality), the player, or the status. The note's format, links and rules values are in [SKILL.md](SKILL.md).

1. **Read the Character note.**
2. **Check the change** against the Trusted Source rules: an item that needs attunement, the attunement limit, a spell the class can prepare and the number it may, the coins the Character has.
3. **Link what is new** as SKILL.md's "Links" says, Campaign homebrew included.
4. **Status.** `retired` or `dead` changes only the `status` line, and the note and its folder stay; `active` brings the Character back.
5. **Identity.** Write the DM's words; a backstory naming a place, NPC or faction follows SKILL.md's "Backstory and the DM's world".
6. **Edit the note**: the Build's lines that change, then every number in Statistics recomputed (an attuned item's bonuses included, a removed one's taken out), and the stat block written again from them (the player too, when that changed). A change it does not show — backstory, appearance, personality, status — leaves it as it is.
7. **Report** what changed, each number that changed with it, each note imported or promoted, and each name left out of the backstory.

Done when the note shows the change, its numbers and stat block follow from the new Build, and no past Build was written.
