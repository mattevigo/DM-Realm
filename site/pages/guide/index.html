DM Realm is a Claude Code plugin for Dungeon Masters running D&D 5th edition. It keeps your campaigns in a Workspace: a folder of Markdown notes that you open in Obsidian. You talk to Claude Code in plain words, and the plugin's skills write and update those notes by a fixed set of rules.

The guide follows the order you will actually use DM Realm in. Read it once front to back, then come back to a lesson when you need it.

Before you start

  • Claude Code, installed and signed in.
  • Obsidian, to read and edit the Workspace. It is optional, but the Workspace is built for it.
  • python3 and curl on your PATH. macOS and most Linux systems already have both.
  • Optional: the Fantasy Statblocks plugin for Obsidian, which renders monsters, NPCs and Characters as stat blocks.
  • Optional: MapForge, if you use it at the table; DM Realm can bring its record of a Session into your notes.

How to talk to it

Every skill has a command, /dm-realm:<skill>, but you rarely need it. Describe what you want and Claude Code picks the right skill:

  • add the Goblin and Fireball
  • a new character for Baldu, a level 3 dwarf cleric
  • prepare the next session: the party reaches the flooded crypt
  • consolidate the last session

The one exception is Setup, which only runs when you type its command. That way nothing turns a folder into a Workspace by accident.

Lost? Ask.

/dm-realm:dmr-ask what should I do now? looks at your Workspace and tells you the next step, with the command to run. It never changes anything.
