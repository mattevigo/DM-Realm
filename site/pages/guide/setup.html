A Workspace is the folder that holds all your campaigns. You set it up once, with dmr-setup, and from then on every other skill works inside it.

Make an empty folder

Setup only runs in a folder that is empty (dot-folders like .obsidian/ or .git/ are fine) or that is already a Workspace. Point it at a folder full of other notes and it refuses, without writing anything.

terminal
$ mkdir "DM Workspace" && cd "DM Workspace"
$ claude

Run Setup

Setup is the one skill you must call by its command:

claude
> /dm-realm:dmr-setup

It asks you three questions, one at a time, and stops after each to wait for your answer.

  1. Workspace Language. Every folder, file name and note will be written in it, and it is fixed for good. Answer in any language: "italiano", "Deutsch", "English".
  2. Edition. The 2014 rules (the 2014 core books and those that followed) or the 2024 rules (the 2024 Player's Handbook, Dungeon Master's Guide and Monster Manual).
  3. Stat blocks. Whether monsters' and NPCs' statistics are written as Fantasy Statblocks fences, or as plain Markdown that needs no plugin. Setup recommends stat blocks when Fantasy Statblocks is installed. Characters keep their stat block either way.

You can skip the questions by answering them up front:

claude
> /dm-realm:dmr-setup italiano, 2024 rules, with stat blocks

Read the preview

Before writing anything, Setup shows you exactly what it will create: the Workspace Config, the eight top-level folders with their names in your language, the Templates, the Obsidian settings it changes and, in a language other than English, the Translation Glossary. This is your chance to rename a folder.

An example; the exact wording varies

Open it in Obsidian

When Setup reports it is done, there is one step left, and it is yours: in Obsidian, choose Open folder as vault and pick the Workspace folder. Setup has already set Obsidian to use wikilinks, to put pasted images in an Attachments folder beside the note, and to read Templates from the Templates folder.

Start Claude Code in the Workspace

Always start Claude Code from the Workspace's root folder. DM Realm notices the workspace-config.yml there and loads the Workspace's language, Edition and folder names at the start of every session.

Running Setup again

A Workspace is set up once, but Setup is also how you maintain it. Run /dm-realm:dmr-setup again inside a Workspace to:

  • Rename a top-level folder. Setup moves it and rewrites every link that points into it.
  • Switch between stat blocks and Markdown. It converts every monster and NPC note, after a preview.
  • Restore missing folders, missing Templates (yours are never overwritten) and the Obsidian settings DM Realm needs.
  • Configure Fantasy Statblocks after you install it, or update its layouts.
  • Bring older notes up to date for MapForge. Stat blocks and item notes that embed their own picture get it named as their Portrait, and item notes get item: true. Setup lists what it added, and each picture it could not find.
  • Point MapForge's bestiary at a folder, if you ask it to.

When MapForge has adopted the folder, Setup also tells you what MapForge reads of the Workspace: the creatures its bestiary misses, and how many items its Treasury lists, with how many have no Portrait.

Language and Edition are fixed

A re-run never changes the Workspace Language. The Edition is fixed once the first rules material is imported. For another language or Edition, set up a second Workspace.
