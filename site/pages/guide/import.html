Your Workspace starts empty. Official material comes in one entry at a time, when you need it, through dmr-import. Ask in plain words:

  • add the Goblin
  • import Fireball, Shield and Misty Step
  • I need the Grappled condition
  • import all the Conditions

Where it comes from

Every official entry comes from one place, the Trusted Source: the machine-readable data published by the 5etools project, at one pinned release. DM Realm ships none of it. The first time a skill needs it, a helper downloads it into a Source Cache on your machine, shared by all your Workspaces and kept across plugin updates.

  • Pinned. The cache stays on one release, so a spell does not change under you between Sessions.
  • Refreshed only when you ask. Say "refresh the Source Cache" when you want the newest data.
  • Never from memory. A helper renders each entry from the data. If the source does not have it, it is not imported.
Pasted text is not imported

Paste a spell from a PDF or a website and DM Realm will look it up in the Trusted Source by name instead. If the source has no such entry, it cannot be Reference, and Claude offers to write it as Homebrew in your own words.

What an import writes

  1. Finds the entry in the version of your Edition. When one name matches several entries (a spell and a feat), it asks which.
  2. Renders it with the plugin's helper: the full text, its description, its images, and for a monster its statistics as a stat block or as Markdown, whichever the Workspace chose.
  3. Translates it into the Workspace Language, term by term, recording every choice in the Translation Glossary so every note says "Palla di Fuoco" the same way.
  4. Writes one note in the right folder (Reference/Spells/Level_3/Fireball.md), with its source in the frontmatter, and its images in Reference's Attachments.

An item note also says it is an item, and names its picture as its Portrait, so MapForge's Treasury lists it and a Treasure on the Map can wear its picture. The picture stays in the note's Description too:

---
source: XPHB p. 225, v2.36.1
item: true
image: "[[Reference/Attachments/Bag_of_Holding.webp]]"
---

An item with no picture still says item: true. Your own Homebrew and Campaign items get the same keys when Claude writes them.

An item that only an Adventure describes goes into that Adventure's Items folder instead of Reference. Monster stat blocks always go to Reference, even when a single Adventure prints them.

Editions and Off-Edition Material

A 2024 Workspace imports the 2024 version of an entry; a 2014 Workspace, the 2014 one. When you ask for something your Edition has no version of, it can still come in as Off-Edition Material, clearly marked. For a player option (a spell, a feat, a class, a species), Claude first tells you it is from the other Edition and asks for your consent.

Spell Indexes

Every time a spell note is written, DM Realm rebuilds the Spell Indexes in the Spells folder: one listing every imported spell by level, and one per class (Spells_Wizard, Spells_Cleric…). They are rebuilt automatically, so never edit them by hand.

Each spell note ends with a Classes line naming the classes whose spell list has it. It names the Player's Handbook classes always, and a class from any other book only once you have imported that class: an imported Artificer shows up on its spells, while a Setting book's own classes (World of Warcraft's Mage, Evoker…) stay out until you import one. Importing a spell or a class brings every spell's line up to date; to do it yourself, ask Claude to bring the Spell Indexes up to date.

Translation Glossary

In a non-English Workspace, the Translation Glossary in DM_Tools records, for each game term, the translation chosen and whether it is the publisher's official translation or a faithful fallback. Edit a row there and later notes follow it.

Just asking is not importing

"How does grappling work?" is a question: dmr-ask answers it from the Trusted Source, naming book and page, without writing anything. Import when you want the note in your Workspace.

Adventures

An official adventure gets its own folder in Adventures. Today DM Realm imports an Adventure's items into it, and writes its README (title, book, level range, Parts) the first time. Importing an Adventure's chapters is not built yet; you can still ask questions about an Adventure's text, and dmr-ask answers them from the source.
