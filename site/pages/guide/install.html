DM Realm is a Claude Code plugin, distributed through its own plugin marketplace on GitHub. You install it once, and it serves every Workspace you make.

Install

Start Claude Code anywhere and type these two commands:

claude
> /plugin marketplace add mattevigo/DM-Realm
> /plugin install dm-realm@dm-realm

The first command tells Claude Code where DM Realm lives. The second installs the plugin, whose skills are then available in every Claude Code session as /dm-realm:<skill>.

Nothing is copied into your folders

The plugin lives in Claude Code's own plugin folder. A Workspace holds only your notes and one small file, workspace-config.yml, which records its language, Edition and folder names.

Check it works

Type /dm-realm: and the skills appear in the command menu. Or ask a question in any folder:

claude
> /dm-realm:dmr-ask how do I start?

What else you need

ToolWhyRequired
python3, curlThe plugin's helpers render official entries and fetch the source data.Yes
ObsidianReads and edits the Workspace as a vault: links, backlinks, templates.Recommended
Fantasy StatblocksAn Obsidian community plugin that renders monsters, NPCs and Characters as stat blocks. Setup configures it when it finds it.Optional
MapForgeA table tool whose record of a Session DM Realm can bring into your notes.Optional

To get Fantasy Statblocks: in Obsidian, open Settings › Community plugins › Browse and search for "Fantasy Statblocks". If you install it after Setup, run Setup again in the Workspace to configure it.

Updating

Claude Code updates installed plugins from the marketplace. To check for a new version by hand, run /plugin, open the DM Realm marketplace and update it. Your Workspaces need nothing: the rules travel with the plugin.

Official data is downloaded on first use

DM Realm ships no D&D content. The first time a skill needs a spell or a monster, it downloads the source data into a local Source Cache, shared by all your Workspaces. More in Bring in official material.
