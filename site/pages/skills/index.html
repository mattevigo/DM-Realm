Each skill is one job. You can call it by its command, /dm-realm:<skill>, followed by what you want, or describe the job in plain words and Claude Code picks the skill. Only dmr-setup must be called by its command.

Starting out

dmr-setup

Turns the current folder into a Workspace, and maintains it when run again.

command only dmr-import

Imports official spells, monsters, items, classes, species, feats and rules, translated.

 dmr-campaign

Starts a Campaign: its folder and a README with pitch, world, party, tone and truths.

 dmr-character

Creates, levels up, rebuilds, updates or transfers a Character.

The Session loop

dmr-session-prepare

Creates the next Session note and fills its Prep.

 dmr-mapforge-import

Brings MapForge's record of a played Session into its Live Notes.

optional dmr-session-consolidate

Closes a played Session: recap, loose threads, Party State, Diary, Character changes.

 dmr-session-narrate

Tells a consolidated Session as a Chapter of the Chronicle.

Any time

dmr-ask

Answers questions about DM Realm, your Campaigns and the rules, and offers Ideas. Changes nothing.

Behind the scenes

Two more skills are loaded by the others and never called by you:

  • dmr-workspace holds the Workspace rules (folders, Scopes, links, names, translation) that every skill follows.
  • dmr-trusted-source reaches the official data through the Source Cache.

The plugin also has two hooks: one tells Claude, at the start of a session, that the folder is a Workspace and in which language and Edition; the other keeps the Spell Indexes up to date after every change.
